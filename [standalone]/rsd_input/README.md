### ✅ Main Features

  - Complete input with notify, text, textarea, number, password, range, checkbox, select, select-multiple
  - Change color, shape and layout (if you know CSS)
  - Fully optimized

### 🔧 Download & Installation

1. Download the latest version from your [keymaster].
2. Unzip the package [rsd_input.zip].
3. Ensure the resource in your resources files like this > "ensure rsd_input".
4. Remember to ensure all required scripts an run SQLs.
6. Configure what you want in the config file.
7. Start the resource and it's ready !
