### ✅ Main Features

  - Add peds you want
  - Choose if you want if they be afraid, escapes, plays anims, wanders, has weapon, talks...
  - Exports for other resources
  - 100% optimized with spawn distance

### 🔧 Download & Installation

1. Download the latest version from your [keymaster].
2. Unzip the package [rsd_ped.zip].
3. Ensure the resource in your resources files like this > "ensure rsd_ped".
4. Remember to ensure all required scripts an run SQLs.
6. Configure what you want in the config file.
7. Start the resource and it's ready !
