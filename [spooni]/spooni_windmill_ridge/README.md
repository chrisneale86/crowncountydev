---------------------------------------------------------
----> Update for spooni_bla_church <----
If you have the spooni_bla_church
copy the File from the "update_for_spooni_bla_church" Folder 
to the "stream" Folder from "spooni_bla_church/stream" and 
to the stream Folder from "spooni_windmill_ridge" and replace it.

After this delete the "Update" Folders. 
Restart Server 
finish.
