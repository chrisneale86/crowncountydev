# SD Farmlands

## 1. Installation
spooni_sd_farming works Standalone.  

To install spooni_sd_farming:
- Drag and drop the resource into your resources folder
  - `spooni_sd_farming`
- Add this ensure in your server.cfg
  - `ensure spooni_sd_farming`
- At the end
  - Restart the server

---------------------------------------------------------
----> Update for sd_hotel_licorne + spooni_sd_farming <----
If you have the sd_hotel_licorne
copy the File from the "update-for-spooni_sd_hotel_licorne" Folder 
to the "stream" Folder from "sd_hotel_licorne/stream" and 
to the stream Folder from "spooni_sd_farming" and replace it.

After this delete the "Update" Folders. 
Restart Server 
finish.
---------------------

---------------------------------------------------------
----> Update for spooni_sd_undertaker + spooni_sd_farming  <----

to the "stream" Folder from "spooni_sd_undertaker/stream" and 
to the stream Folder from "spooni_sd_farming" and replace it.

finish.
