## Installation

1. Ensure your server is linked to your **Keymaster** account.

2. Check that oxmysql is installed and ensured above

3. Make sure that **sirevlc_horses** is already installed and ensured above.  
   The **sire_menu** resource is also required (check your Tebex email or see the file section in our Discord) it should be ensured above all other sire's resources.
   
4. Place the `sirevlc_wagons` resource into your server `resources` folder.
⚠️ Use an archive extractor such as **WinRAR** and ftp software such as Winscp. Make sure it's transfer mode is in **BINARY MODE**.
Ensure the **.fxap files** are correctly imported for:
- `sirevlc_wagons`


5. Add the following line to your `server.cfg` or `resources.cfg`:
   ```cfg
   ensure sirevlc_wagons
```
it should look like this : 

```
 ensure sirevlc_horses 
 ensure sirevlc_horses_interactions
 ensure sirevlc_wagons
```


6. Import `sirevlc_wagons.sql` into your database.
7. Start the server and enjoy.
