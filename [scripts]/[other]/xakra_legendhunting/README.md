# xakra_legendhunting

# REQUIREMENTS
- [vorp_menu](https://github.com/VORPCORE/vorp_menu)
- [vorp_core](https://github.com/VORPCORE/vorp-core-lua)
- [vorp_inventory](https://github.com/VORPCORE/vorp_inventory-lua)
- Open source framework functions to adapt the script to any framework

# DESCRIPTION
With this script, players can initiate various legendary hunts by following animal tracks. During a hunt, players may encounter wild animals or competing poachers. The objective is to deliver the animal's body or pelt to the location where the hunt started.

🔐 Required Items: Sets the items required to start each Legendary Hunt.
🛡️ Animal Health: Customize the HP of each legendary animal for balanced combat.
🎁 Rewards: Configure a randomized list of rewards, including currency and items.
📉 Hunting Limits: Define how often players—and the entire server—can complete a hunt with cooldown timers and restriction settings.
🔄 Mission Resets: Each location may have a limited number of legendary hunts available, rotating automatically at intervals you define.

🐾 Currently Included Legendary Animals:
- Bear
- Alligator
- Wolf
- Ram
- Boar
- Panther
- Moose
- Buck
- Bison
- Beaver

# YOU CAN CONFIGURE
Language: English and Spanish by default
Menu alignment
Keys
Webhook
Enable or disable blips for poachers and legendary animals
Enable or disable bleeding to control how fast animals die
Enable or disable skinning for non-legendary animals
Customize the color of objective blip and route
Locations: NPCs, coordinates, job restrictions, blacklist of legendary hunts, and required items
Custom health values for each legendary animal
Rewards: Randomized rewards including currency and items
Hunting limits per player or globally, with cooldowns and custom limit rules
All script coordinates, including NPCs, enemy spawns, animals, and track positions

# INSTRUCTIONS TO INCORPORATE SCRIPT
- Copy the script into a folder (to choose) from the 'resources' folder.
- Add 'ensure xakra_legendhunting' in the 'Resources.cfg' document
- Check the config.lua file and configure to adapt the script, change the language, Gus locations, etc...
