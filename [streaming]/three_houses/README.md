# Crow Maps | PROPS | Three Houses
This pack includes 3 units in total, made with care and at an affordable price.

## 1. Requirements
After purchase, you will receive an email with the file, download and install as per the instructions below.

### 2. Installation
- Create folder ```three_houses``` in folder ```resources```
- Unpack archive ```three_houses``` into folder ```three_houses```
- Add ```ensure three_houses``` to server.cfg.
