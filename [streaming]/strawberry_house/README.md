# Outlaw Builders | MLO | Strawberry House
This pack includes 8 units in total, made with care and at an affordable price.

## 1. Requirements
After purchase, you will receive an email with the file, download and install as per the instructions below.

### 2. Installation
- Create folder ```strawberry_house``` in folder ```resources```
- Unpack archive ```strawberry_house``` into folder ```strawberry_house```
- Add ```ensure strawberry_house``` to server.cfg.
