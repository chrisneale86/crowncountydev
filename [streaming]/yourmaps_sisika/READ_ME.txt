-------------

Here, we will give you the information you will need to install this package:

- Unzip the resource into your server resources
- Ensure the resource "yourmaps_sisika"

Do the same for "yourmaps_rugs_pack" if you want to use this pack.

The HeavyFurnace is inside the "yourmaps_sisika" so you won't need anything.

-------------

If you need door hashes please use the .txt file with Door Hashes.
All Towers doors can be Locked for no escape! You can edit them also on the "sis_tower_doors.ymap".

-------------

Check the IPL list, so you can have the basement tunnel open or closed, as other IPL you might need to add or remove in you interiors file.

-------------

This asset don't come with a script for jobs! You need to make the script from yourself or buy it from a developer!
