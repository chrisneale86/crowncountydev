# mlo_witch_house

## 1. Requirements
You have received an email with the file **mlo_witch_house**. Download it and install it according to the instructions below.

## 2. Installation
 - [ ] Create folder **mlo_witch_house** in folder **resources**
 - [ ] Unpack archive **mlo_witch_house** into folder **mlo_witch_house**
 - [ ] Add **ensure mlo_witch_house** to server.cfg.
 - [ ] Open the **config.lua** file and set the values to *true* in the line corresponding to your project. Set the values to *false* in the lines of missing projects. You can also enable or disable the ghosting feature

## 2.1 Installation of two or more houses
 - [ ] In case you have more than one witch_house the end result of the installation should be as in the image **sample.png** 
One of the projects is set up as per #2. And from other projects only folders with contents are copied:
```
[forest_witch_house]
[swamp_witch_house]
[mountain_witch_house]
```
into the folder 
```[mlo_witch_house]```
